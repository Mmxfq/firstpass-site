Evidence standard

Unknown stays unknown.

Every report separates visible evidence from interpretation. Missing or conflicting information is never converted into a confident-sounding conversion claim.

ObservedThe report cites the public page, element, quote, or browser state that supports the finding.
ContradictedWhen a supplied claim conflicts with public evidence, both are recorded and the conflict is flagged.
UnknownThe report names the missing evidence, decision at risk, bounded next check, owner, and resolution rule.
