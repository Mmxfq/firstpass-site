# FirstPass

Free, browser-only tools for release asset validation, homepage clarity checks,
and hero copy drafting, plus public evidence-based review samples.

Live site: https://mmxfq.github.io/firstpass-site/

## Free tools

- [Release Contract Preflight](https://mmxfq.github.io/firstpass-site/release-contract-preflight.html)
  compares a public GitHub release's actual asset inventory with explicit
  platform, architecture, filename, checksum, and documentation-reference rules,
  and exports JSON and HTML evidence.
- [Developer Tool Release Checklist](https://mmxfq.github.io/firstpass-site/release-checklist.html)
  is an eight-point self-check for the public install and first-run path.
- [SaaS Homepage Clarity Checklist](https://mmxfq.github.io/firstpass-site/checklist.html)
  is a ten-point self-check for positioning, proof, risk, and call-to-action clarity.
- [SaaS Hero Brief Builder](https://mmxfq.github.io/firstpass-site/hero-brief.html)
  turns six inputs into a structured hero brief.

Every tool runs entirely in the browser. Inputs are not uploaded, stored, or
tracked, and no account is required.

## Public samples

Evidence-based review notes on public products live under `docs/*-mini-teardown.html`.
Each material claim is labeled observed, contradicted, or unknown, and the notes
describe public pages on the dates stated.

## What is in this repository

- `docs/` — the GitHub Pages site: free tools, public samples, `llms.txt`, and `sitemap.xml`
- `report-template.md` — the structure used for evidence-based review notes

## Standards

- no fake credentials, testimonials, scarcity, or results claims
- no passwords, private analytics, or customer data
- no repeated unsolicited messages
- no conversion or revenue guarantees
- no paid services or products are offered here
